# 📝 scan-repo

**README пишет себя сам.**

Скармливаешь ссылку на репозиторий — локальная нейросеть читает код и пишет за тебя документацию: описание, фичи, стек, установку, примеры. Твой код **не покидает твой компьютер** — никаких облачных API.

## 🚀 Быстрый старт

1. Установи **Git** и **[Ollama](https://ollama.com)**, скачай модель:
   ```bash
   ollama pull saiga        # или llama3 — укажешь при запуске
   ```
2. Поставь зависимости (их всего две):
   ```bash
   git clone https://github.com/4elobrek9/scan-repo.git
   cd scan-repo
   pip install GitPython requests
   ```
3. Запусти и ответь на три вопроса:
   ```bash
   python main.py
   ```

## ⚙️ Что происходит под капотом

1. 📥 Клонирует репозиторий во временную папку (потом приберёт за собой).
2. 🔍 Сканирует файлы, пропуская мусор (`.git`, `node_modules`, сам README…), определяет языки.
3. 🧠 Разбирает каждый файл с помощью LLM: назначение, классы, функции, зависимости. Большие файлы режет на куски и объединяет анализ.
4. 📐 Генерирует секции README по строгой JSON-схеме — структура предсказуемая, а не «как модель настроена».
5. 📄 Собирает итог: описание, обзор, фичи, стек, установка, примеры, авто-дерево структуры проекта, разделы «Вклад» и «Лицензия».

И да, пока нейросеть думает — консольная анимация развлекает («Переводит код на язык единорогов...»). Скучно не будет.

## 💡 Советы

- **Модель решает.** `saiga` быстрая, `llama3` (или крупнее) — заметно связнее текст.
- **Время = размер репо.** Каждый файл — запрос к LLM; на большом проекте запасись кофе.
- **Интернет нужен дважды:** склонировать репо и один раз скачать модель. Дальше — офлайн.
- **Вычитывай результат.** LLM может ошибаться — сгенерированный README это черновик, а не истина.
- 🎨 Шаблон в `main.py` добавляет баннер с соцсетями автора — убери этот блок, если хочешь чистый корпоративный стиль.
